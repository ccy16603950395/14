# Multi-Agent Workflow

## End-to-end flow

User Requirement  
→ Problem Definition Agent  
→ Mechanism Agent  
→ Model Design Agent  
→ Code Implementation Agent  
→ Validation Agent  
→ Documentation Agent  
→ Human Review  
→ Next Iteration

## Flow explanation
- **Problem Definition Agent**: 形成目标边界、验收标准和 MVP 范围。
- **Mechanism Agent**: 输出扩散-退化-损伤机理规则。
- **Model Design Agent**: 形成模块、接口和数据结构设计。
- **Code Implementation Agent**: 实现代码与可运行示例。
- **Validation Agent**: 运行测试并检查机理一致性和输出工件。
- **Documentation Agent**: 汇总形成技术文档和 API 页面。
- **Human Review**: 人工审阅并提出新需求或缺陷反馈。
- **Next Iteration**: 回到问题定义，进入下一轮闭环。
