# API Documentation Overview

This folder contains module-level API docs:

- `config_api.md`: simulation parameter configuration.
- `grid_api.md`: grid and material partition generation.
- `materials_api.md`: material property structures and defaults.
- `transport_api.md`: concentration diffusion and boundary handling.
- `degradation_api.md`: degradation, damage, modulus, and strength updates.
- `simulation_api.md`: orchestrator class and runtime flow.
- `visualization_api.md`: plotting and output figure helpers.
