# Documentation Agent
- **Agent 名称**: Documentation Agent
- **核心职责**: 将代码与验证结果整理为可交付文档。
- **输入内容**: 所有 Agent 输出、代码接口、验证报告。
- **输出内容**: README、API 文档、流程与阶段报告（对应 `docs/agent_outputs/06_documentation_report.md`）。
- **与其他 Agent 的协作关系**: 汇总各 Agent 结论并反向驱动下一轮需求澄清。
- **本项目中的具体贡献**: 维护 docs/api 与 multi-agent 工作流文档一致性。
